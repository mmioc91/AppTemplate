# Ubiquitous language

The words the product's users see (the UI language) and the English names the code uses for them. One row per
term; a term that means two things gets two rows. Code, ADRs and docs use only the English column; the UI and its
translations use only the first.

| UI term | Code name | Meaning | Kind |
|---|---|---|---|
| *(e.g. narudžba)* | `Order` | what a customer places | aggregate |
| *(e.g. kotizacija)* | `EntryFee` | what a participant pays to take part | value object |
